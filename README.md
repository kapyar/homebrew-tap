# kapyar/tap

Homebrew tap for [Clementine](https://getclementine.app) — drag any file, tap Shift, drop on a format.

```bash
brew install --cask kapyar/tap/clementine
```

This is the direct-download edition (Developer ID signed and notarized by Apple, universal for Apple silicon and
Intel, macOS 15 or later). Clementine is also on the [Mac App Store](https://apps.apple.com/app/id6824898685).
